This is a fully client side application. The OCR happens fully in the browser. The data is not sent to any server. The data is processed in the browser and then the results are shown to the user. The application uses Tesseract.js for OCR and some custom code for processing the OCR results and showing them to the user. The application also uses some libraries for UI and other functionalities.
